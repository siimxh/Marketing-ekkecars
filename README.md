# Marketing ekkecars

Repo di lavoro per le campagne pubblicitarie di ekkecars (B2C, Meta Ads).

- **Chi lavora qui:** Simone e Loris creano copy, concetti e campagne.
- **Chi decide:** Beppe (Giuseppe) ha l'ultima parola prima della messa online.

## Come usare il repo

Prima di scrivere qualsiasi copy, leggi `contesto/` per intero. È la fonte di verità.
**Se un'informazione non c'è, va chiesta, non inventata.**

| Cartella / file | Cosa contiene |
|-|-|
| `contesto/01-azienda.md` | Chi è ekkecars, team, modello B2C, processo di vendita, altre aree di business |
| `contesto/02-avatar-pain-obiezioni.md` | Cliente ideale, pain point, obiezioni ricorrenti |
| `contesto/03-fatti-e-claim.md` | I fatti e i claim confermati, il metodo ekkecars, la social proof (versione unica) |
| `contesto/04-regole-di-scrittura.md` | Lessico, tono, struttura dei body, CTA, rassicurazioni, metodo di lavoro |
| `contesto/05-libreria-copy.md` | Hook approvati e CTA definitiva, pronti da riusare |
| `campagne/` | Una cartella per campagna: brief, idee, copy in lavorazione e approvati |
| `archivio/` | Lavori chiusi o mai andati online, con lo storico di cosa è stato bocciato e perché |
